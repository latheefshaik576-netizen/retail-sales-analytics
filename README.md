# Retail Sales Performance & Business Intelligence Dashboard

**Portfolio project for data analyst internship applications**

> **Data transparency:** `data/retail_sales_simulated.csv` is a synthetic practice dataset. It does not represent real company transactions or verified business outcomes. Clearly label results as simulated.

## Objective
Analyze sales, profit, units, product categories, regions, monthly trends, and discount patterns.

## Tools
Python/Pandas, SQL (SQLite-compatible), Power BI (dashboard guide included), Matplotlib.

## Files
- `data/retail_sales_simulated.csv` — practice dataset
- `analysis.py` — data checks, summaries, charts
- `sql/analysis_queries.sql` — business analysis queries
- `powerbi_dashboard_guide.md` — dashboard layout and DAX measures
- `case_study.md` — portfolio case study
- `reports/` — generated summaries and charts

## Run
Requires Python 3.10+:
```bash
python -m pip install pandas matplotlib
python analysis.py
```
Then import the CSV into Power BI Desktop and follow the dashboard guide. Check all outputs before writing conclusions.
